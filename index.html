Backup e segurança

Os dados ficam salvos neste navegador do aparelho. Exporte um backup regularmente para não perder seus registros se limpar os dados do navegador ou trocar de celular.

Não inclua senhas bancárias ou dados sensíveis de terceiros. O app não envia seus dados para um servidor; nesta versão eles ficam no armazenamento local deste navegador e não são sincronizados entre aparelhos.
